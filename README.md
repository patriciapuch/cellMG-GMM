# cellMG-GMM
This repository provides additional material for the manuscript "Outlier-robust multi-group Gaussian mixture modeling with flexible group reassignment" (DOI: 10.48550/arXiv.2504.02547).

It includes additional code for full reproducibility of the paper in the folder "code".

The code for cellGMM (Zaccaria et al. 2025) is also available on the respective repository (https://github.com/giorgiazaccaria/cellGMM).
